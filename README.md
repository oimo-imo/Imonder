# Imonder

指だけで作れる 3D モデリングアプリ（Android / Windows）。仕様は `3Dモデリングツール 仕様書` を参照。

- UI: Flutter (`lib/`)
- コア・描画: Rust (`rust/`)。C ABI を `dart:ffi` で呼ぶ。現状は CPU ラスタライザ（`render.rs`）で、wgpu への差し替えを想定した境界になっている
- 複数選択: 下のバーの「追加選択」をオンにするとタップで選択に足す／外す（マウスはShift+クリック）。「全選択」、シーン一覧のチェックボックスでも選べる。選んだもの全部をまとめて移動・回転・拡大縮小・複製・削除
- グループ: 2つ以上選んで「グループ化」。どれかをタップすると全体が選ばれる。差し込んだプリセットは自動でグループになる
- オブジェクトモード: タップでオブジェクトを選択。下のバーで追加（立方体・平面・円柱・円錐・球・トーラス）・複製（同じ位置に）・削除、移動・回転・拡大縮小。上バーの「シーン」で一覧・表示/非表示・選択
- 撮影（上バーのカメラ）: 画面の枠の中をPNGで写真に保存（アルバム「Imonder」）。プリセット（箱庭＝斜め上からの平行投影、斜め、正面、真上、横）で配置して、指で調整。縦横比（1:1・4:5・3:4・16:9・9:16）、サイズ（1K〜4K）、平行投影・グリッド・辺・背景透過を切り替え。撮影をやめると編集時の視点に戻る
- モディファイア（下のバー）: ミラー（原点を通る面でX/Y/Zに対称、結合で継ぎ目をつなぐ）と配列（個数・間隔・方向、結合）。元の形は残り、表示・選択・スナップ・撮影・書き出しは結果の形で扱う。目で表示切替、✓で適用（焼き込み）、ゴミ箱で削除。オブジェクトには原点があり、オブジェクトモードの移動・回転・拡大縮小で一緒に動く
- スナップ（上バーの磁石）: 移動は他のオブジェクトの面・頂点にぴったり接する位置へ吸着（斜面や尖った先にも）、近くに何もなければグリッドへ。回転は15°、拡大縮小は0.1倍刻み
- プリセット: シーン一覧の「プリセットに登録」で、表示中のオブジェクト一式を登録。追加メニューから今の作品に差し込める（保存した位置のまま）。ギャラリーの「新規」でプリセットから作品を始められる。長押しで名前変更・削除
- 平行投影: ギズモの下のボタンで、編集中も透視⇔平行を切り替え
- 書き出し（シーン一覧の共有アイコン）: glTF（.glb）か OBJ、表示中すべてか選択中だけ。Z上をY上に変換するので Blender・Unity でそのまま立つ。Android は保存先を選ぶ画面、Windows は名前を付けて保存
- 保存: 変更すると自動で端末に保存（2秒ごと、アプリを離れる時も）。ギャラリー（上バー左端）で作品の一覧・新規・名前変更・削除。形式は独自バイナリ `.imnd`（`rust/src/scene.rs`）
- 編集モード: 頂点・辺・面をタップで選択（マウスは Shift+クリックで追加選択）、移動ツールで矢印をドラッグして軸方向に移動、2本指タップで元に戻す・3本指タップでやり直す
- 編集ツール（下のカプセル、横にスクロール）: 移動・回転（リングをドラッグ）・拡大縮小（矢印の先で軸方向、中央の白い点で全体）、押し出し・インセット・ベベル・結合・削除、全選択。ループカットはツールを選んで辺をタップ。押し出し・インセット・ループカット・ベベルは、直後に出るスライダーで値を調整できる（直前の操作を調整）
- 視点: 右上のギズモの軸をタップでその方向へ、ドラッグで回転、背景タップでパースに戻る
- 操作: タッチ = 1本指で回転 / 2本指で移動＋ピンチズーム。マウス = ドラッグで回転、Shift＋ドラッグ or 右ドラッグで移動、ホイールでズーム

## 開発

```sh
cargo test --release --manifest-path rust/Cargo.toml
cargo build --release --manifest-path rust/Cargo.toml   # Dart側FFIテスト・Windows実行に必要
flutter test && flutter analyze
```

Android は `cargo ndk -t arm64-v8a -o ../android/app/src/main/jniLibs build --release`（`rust/` 内）で `.so` を作ってから `flutter build apk`。

## リリースとアプリ内アップデート

1. GitHub の Actions → **Build & Release** → Run workflow で `version`（例 `0.1.1`）を入れる。または `v0.1.1` タグを push。
2. APK（`imonder-android-arm64.apk`）と Windows zip（`imonder-windows-x64.zip`）が GitHub Releases に上がる。
3. アプリは起動時に最新リリースを確認し、新しければ上バーのアップデートアイコンに印が付く。タップ → ダウンロード → インストール。
   - Android: システムのインストーラが開く（初回は「この提供元のアプリを許可」が必要）
   - Windows: 終了 → ファイル入れ替え → 自動で再起動

### Android の署名について
更新するには前回と同じ鍵で署名する必要がある。既定ではリポジトリ内の開発用キー（`android/imonder-dev.jks`）を使う。
自分だけの鍵に変えるときは、Secrets に `ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS` / `ANDROID_KEY_PASSWORD` を登録する（ただし鍵を変えると既存インストールは一度アンインストールが必要）。
